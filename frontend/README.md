# MERN eLearn Frontend

The refreshed UI uses the Coolors palette of brand `#2774f6`, accent `#ff7a59`, soft highlight `#7fb3ff`, deep ink `#134a9a`, and the light canvas `#f8fafc`. Typography is handled by the Inter family (loaded in `public/index.html`). Key presentation files live in `src/components` (Nav, Badge, Card, Spinner) and `src/pages` (Home, Courses, CourseDetail, Login, Register, Dashboard, AdminPanel) with shared tokens defined in `tailwind.config.js`, `src/index.css`, and `src/config.js`. Admins log in by choosing **Admin panel** on the login screen (only the stored admin email/password will pass). After authenticating, they can manage courses and users via dedicated tabs plus review the execution lab checklist. To verify the full stack locally:

1. `cd backend && npm install && npm start` (runs the Express/Mongoose API on port 5000).
2. `cd frontend && npm install && npm start` (runs CRA with Tailwind v3 styling).
3. Optionally run `npm run build` inside `frontend` to confirm a production build.
